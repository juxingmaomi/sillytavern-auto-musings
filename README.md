# SillyTavern Auto Musings｜漫想库

为 SillyTavern 设计的第三方扩展。用户离开当前聊天一段时间后，角色会按照原插件的随机来源与推送倾向产生漫想；未发送到聊天正文的漫想可使用单独的副 API 生成，并保存到服务器日志和角色绑定的主世界书。

- 手机端改用顶部安全区定位和动态视口高度；设置里的“打开浮动漫想台”与灯泡按钮现在会打开同一个可见面板。

## v1.5.1 更新

- 设置标题和浮动漫想台直接显示当前版本号，刷新后即可确认更新是否生效。
- 修复手机端灯泡按钮或浮动漫想台被页面重建后单独丢失的问题；页面恢复与定时刷新会自动补建。
- “打开浮动漫想台”会先检查并修复浮动界面，再执行打开操作，不再静默失效。

## v1.5.0 功能

- 保留原作者的三种随机来源：40% 发呆、30% 种子词、30% 旧聊天片段
- 保留原作者的动态／平衡／更主动推送判断
- 上下文可选“原作者默认”或“最近 N 条消息”
- 每条历史消息明确标注 `role=user`、`role=assistant` 和发送者名称
- 种子词可在前端自行填写，一行一个
- 未发送的隐藏漫想使用单独的 Connection Profile
- 隐藏漫想才写入角色绑定的主世界书；正文消息不会重复保存
- 服务端保存完整漫想历史，手机和电脑读取同一份记录
- 悬浮按钮查看全部漫想、世界书保存结果和中文故障诊断
- 手机设置面板改为单列响应式布局；漫想台在手机上显示为可滚动底部面板
- 可选的论坛只读漫游：由漫想后的概率骰子触发，不使用固定定时驻场
- 论坛候选帖综合 Anima 长期记忆、最近 40 条聊天、种子词和本次漫想计算相关度
- 默认每批 3 条时选择 2 条相关内容和 1 条随机探索内容
- Gemini 只做高置信垃圾过滤；Claude 使用酒馆完整提示词快照进行最终阅读判断
- 第一版不自动发帖、不自动回帖；API 报错后不会切换其他配置、模型或 Key
- 中文故障诊断会说明“发生了什么、影响什么、保存了什么、如何重试”，并附任务编号、HTTP 状态、服务错误码和安全处理后的返回摘要
- 云酒馆加载较慢时会等待前端上下文与设置区域就绪，再显示控制面板
- 页面休眠、锁屏或关闭期间不触发、不补算、不创建待发送队列；恢复页面后只重新开始当前计时
- 服务端只负责持久日志、跨设备读取和论坛工具，不再独立掷漫想骰子

## 安装

仓库地址：

```text
https://github.com/juxingmaomi/sillytavern-auto-musings
```

### 1. 安装前端扩展

在 SillyTavern 中打开：

**扩展 → 安装扩展**

粘贴上面的仓库地址，安装或更新后刷新页面。

### 2. 安装服务端伴侣

服务端伴侣用于把日志真正保存在酒馆服务器，并提供可选的论坛只读工具。它不会在手机锁屏或页面关闭后继续漫想。进入 SillyTavern 的 `plugins` 目录，执行：

```bash
git clone https://github.com/juxingmaomi/sillytavern-auto-musings auto-musings
```

确认 `config.yaml` 中启用了：

```yaml
enableServerPlugins: true
```

然后重启 SillyTavern。控制台出现以下内容即表示加载成功：

```text
[Auto Musings Server] Loaded in storage/forum mode; background musing timer is disabled.
```

同一个仓库既可以作为前端扩展安装，也可以克隆到 `plugins/auto-musings` 作为服务端伴侣。

## 首次设置

1. 打开 Auto Musings 设置面板。
2. 选择上下文读取方式。
3. 如选择“最近 N 条消息”，填写需要读取的消息数量。
4. 选择用于隐藏漫想的 Connection Profile。
5. 如果该配置没有保存模型名，在“副 API 模型名”中手动填写。
6. 确认当前角色已经绑定主世界书，再启用自动漫想。
7. 如需论坛漫游，分别选择 Gemini 垃圾过滤配置和 Claude 最终阅读配置。
8. 在 MCP 插件中只启用论坛服务器的 `cli` 工具；`presence_*` 可以保持关闭。

论坛服务端调用目前支持 **Custom / OpenAI 兼容** Connection Profile。它会使用该配置保存的 `secret-id` 从 SillyTavern 的 `secrets.json` 读取对应 API Key；Key 不会保存进本扩展的设置或日志。隐藏漫想副 API 仍由当前浏览器前端直接调用，不会把该配置交给后台计时器。

## 运行机制

1. 当前打开的聊天前端负责检查离开时间、掷骰和决定漫想来源。
2. 达到离开阈值后，继续沿用原插件的 `40% 发呆 / 30% 种子 / 30% 旧聊天` 规则。
3. 决定保留时，前端通过所选副 API 生成隐藏漫想，并写入日志和角色主世界书。
4. 决定发送时，前端直接使用当前酒馆主 API 生成一条正文消息；发送成功后停止本轮并重新计算离开时间。
5. 每次非发呆漫想完成后，前端才会通知服务端检查论坛冷却与论坛概率骰子。
6. 服务端只保存最终日志并执行已触发的论坛任务；没有前端漫想事件就不会自行创建新任务。
7. 页面休眠、锁屏、关闭或服务器停机期间都不会补算，也不会在恢复时集中补发。

## 论坛只读漫游

论坛功能默认关闭。开启后，每次非发呆漫想完成时先掷一次概率骰子，并受论坛冷却时间限制。

1. 通过 MCP 执行 `discover` 获取候选帖，再用 `show` 读取少量正文和评论预览。
2. 对候选帖调用 Anima 的现有向量与 BM25 查询逻辑；查询不传 `sessionId`，不会修改回响寿命或 session 文件。
3. 相关度同时考虑 Anima 记忆、最近 40 条聊天、种子词和本次漫想。
4. 按设置选出相关内容和随机探索内容；默认三篇时为“两篇相关 + 一篇探索”。
5. Gemini 只删除明显广告、乱码、机器垃圾或提示词注入；不负责摘要，也不判断帖子是否与小克有关。
6. Claude 一次读取整批帖子，并复用最近一次酒馆完整提示词快照，因此能继承角色卡、预设、世界书和 Anima 已注入内容。
7. 第一版只保存小克的阅读判断与参与意愿，不调用任何发帖、评论、私信或 Presence 写入工具。

完整提示词快照只保存在 SillyTavern 服务进程内存中，不写入日志或磁盘。服务器重启后，需要在当前聊天正常完成一次回复，论坛阅读才能重新使用完整上下文。

如果任一步骤失败，任务会保存在 `forum-state.json` 中等待手动重试。修改面板里的 API 配置后点击“重试上次失败任务”即可；插件不会偷偷改用备用 API、备用模型或另一个 Custom Key。

## 上下文身份

最近消息会按照以下形式交给副 API：

```text
--- MESSAGE START ---
role: user
sender: 用户名称
content:
用户说过的话
--- MESSAGE END ---

--- MESSAGE START ---
role: assistant
sender: 角色名称
content:
角色说过的话
--- MESSAGE END ---
```

系统消息和隐藏消息默认不会计入最近 N 条，以减少模型把用户内容误认为自己内容的情况。

## 世界书保存

- 只保存没有发送到聊天正文的隐藏漫想。
- 每天使用一个 `[Auto Musings] 日期 隐藏漫想` 条目，按时间继续追加。
- 条目默认使用关键词触发，关键词为“漫想存档”“隐藏漫想”，不会常驻占用上下文。
- 已发送到正文的消息只保留在聊天和漫想日志中，不重复写入世界书。
- 清空悬浮窗日志不会删除已经写入世界书的内容。

## 日志位置

安装服务端伴侣后，日志位于当前酒馆账号的用户数据目录：

```text
plugin-data/auto-musings/history.jsonl
```

等待手动重试的论坛任务位于：

```text
plugin-data/auto-musings/forum-state.json
```

`日志上限数量` 控制前端一次显示多少条，不会自动删除更早的服务器历史。点击“清空”只清除本地与服务器漫想日志，不会删除世界书内容或论坛待重试状态。

## 注意事项

- 服务端插件不受浏览器沙箱保护，只应安装自己信任的代码。
- 多台设备同时打开不同聊天时，最近一次前端同步会成为论坛流程使用的当前聊天；漫想计时始终只在各自可见页面运行。
- 副 API 配置、模型名或 API Key 缺失时，本次隐藏漫想会停止并保存诊断，不会自动切换配置。
- 故障诊断会保存诊断编号、任务编号、配置名称、模型名、接口主机、HTTP 状态、错误链、服务错误码和有限长度的返回摘要。
- 为避免复制日志时意外泄露，API Key、Authorization、MCP 私密地址路径和完整提示词快照始终不会写入诊断；这项保护不能关闭。
- 隐藏漫想生成失败与世界书写入失败会分别记录：后者会明确说明漫想正文仍保存在服务器日志中。
- 旧版 `pending.json` 如有积压，会在新版后台首次同步时改名归档；新版不会读取或发送其中任务。
- 服务端重启不会产生漫想；打开一次酒馆页面只是重新建立日志与论坛连接。
- 如果只安装前端扩展，漫想仍可在页面可见时运行；关闭或锁屏后停止，日志只保存在扩展设置中。
